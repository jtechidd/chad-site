Thank you for dropping by, no matter how you discovered this website, I truly appreciate it a lot.

I created this website mainly to share my thoughts, works, and projects that I am working on. All contents on this website will not and never be using AI to mindlessly generating. I only use it as a chatbot assistant tool that is so-called a powerful search engine.

### How was this website created?
Even though there are a lot of frontend frameworks that help building static web pages. I still feel that I am not under control (my skill issue anyway). And it often waste my time to study a picked framework, even though the truth is nowadays I can just do a prompt with an AI agent. It ends up that I am not able to control how my website is going to be.

So I went rough, building this website manually, just using a simple Python script with some basic tools like:
- [Marko](https://marko-py.readthedocs.io/en/latest/), there are tons of markdown library that I can use, but this one provide a simplicity of extensibility and workflow that I think it make sense, like having an intermediate AST that I can work with before render into HTML.
- [Jinja2](https://jinja.palletsprojects.com), as a template engine, mainly used to produce HTML files.
- [SASS](https://sass-lang.com), to compile .scss files to .css, making working with CSS more comfortable.

I want to give a shout out to some free tools that I used to build this website, those are:
- [Free WordArt Generator](https://www.makewordart.com/), I used this to generate a simple web logo as shown above.
- [98.css](https://jdan.github.io/98.css/), The CSS to style your web page to make it looks like Windows 98.
- [Web Design Museum](https://www.webdesignmuseum.org/), There are tons of old website design that I can take a look.

I intended to make this website look a bit old and timeless. I have been able to crystallize the idea that older websites contain a lot of text and hyperlinks. The layout of website is not too spacey and carefully designed, thinking like when we just drag and drop textboxes arbitrary on the MS Word.

If you are interested in how my website was built, please check out this [repository](https://github.com/jtechidd/chad-site).
